- `SKILL.md` — 可运行的人物 Skill：5 个心智模型、9 条决策启发式、回答工作流（Agentic Protocol）、表达 DNA、诚实边界
- `references/research/00-source-mindmap.md` — 一手素材完整转写

- `scripts/quality_check.py` — 女娲 Phase 4 质量门禁（6 项标准）
- `LOOP.md` — /loop 迭代任务与闭环条件定义

## 使用

本目录自包含，可整体拷出作为独立 GitHub 仓库发布。
