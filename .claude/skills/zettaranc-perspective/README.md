# Z哥.skill — zettaranc-perspective

zettaranc（Z哥，本名万千）交易思维的认知操作系统。由 [女娲 · Skill造人术](https://github.com/alchaincyf/nuwa-skill) 蒸馏生成（快速档网络调研 + [lululu811/zettaranc-skill](https://github.com/lululu811/zettaranc-skill) 社区语料交叉验证）。

前阳光私募冠军基金经理 → B站221万粉UP主。核心体系：不预测只应对、概率思维、时代主线、永不套牢（少妇战法/只输一根K线/四块砖）、资金行为视角。2014→2017→2026 跨12年言论逐字级一致性验证。

## 内容

- `SKILL.md` — 可运行的人物 Skill：5 个心智模型、10 条决策启发式、回答工作流、表达 DNA、4 对内在张力、诚实边界（含 title 争议与业绩考证）
- `references/research/00-research-digest.md` — 调研摘要与来源链
- `scripts/quality_check.py` — 女娲 Phase 4 质量门禁（6 项标准）
- `LOOP.md` — /loop 迭代任务与闭环条件（含活跃人物的时效检查规则）
- `integration/` — 量化选股 agent team 集成套件（交易纪律官子代理 + 安装说明）

## 使用

放入任意项目的 `.claude/skills/` 目录，对 Claude 说「用Z哥的视角分析…」即可激活。
与 `jin-jiancheng-perspective` 配合使用：金渐成管「买不买」（风控闸门），Z哥管「怎么买怎么卖」（纪律官）。

本目录自包含，可整体拷出作为独立 GitHub 仓库发布。
